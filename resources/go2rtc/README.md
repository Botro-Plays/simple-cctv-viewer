# go2rtc Binary

Download the go2rtc binary for your platform and place it in this directory.

## Download Links

- **Windows (amd64):** https://github.com/AlexxIT/go2rtc/releases/latest/download/go2rtc_win64.exe
- **Linux (amd64):** https://github.com/AlexxIT/go2rtc/releases/latest/download/go2rtc_linux_amd64
- **macOS (amd64):** https://github.com/AlexxIT/go2rtc/releases/latest/download/go2rtc_darwin_amd64
- **macOS (arm64):** https://github.com/AlexxIT/go2rtc/releases/latest/download/go2rtc_darwin_arm64

## Installation

1. Download the appropriate binary for your platform
2. Rename it to `go2rtc.exe` (Windows) or `go2rtc` (Linux/macOS)
3. Place it in this directory

## Verification

After installation, verify the binary works:

```bash
# Windows
.\go2rtc.exe --version

# Linux/macOS
./go2rtc --version
```
